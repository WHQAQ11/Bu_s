## 🏗️ 架构变更

### 认证流程变更
**之前**:
```
用户输入 → Axios API → JWT Token → localStorage
```

**现在**:
```
用户输入 → Supabase Auth → 自动会话管理 → 状态同步
```

### 数据存储变更
**之前**:
- localStorage存储认证状态
- 外部API处理用户数据

**现在**:
- Supabase自动管理会话
- 用户资料存储在Supabase数据库
- 完整的RLS安全策略

## 🔧 开发指南

### 本地开发设置
1. 复制 `.env.example` 为 `.env.local`
2. 填入实际的Supabase配置：
   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key-here
   ```

### 运行项目
```bash
npm run dev    # 开发服务器
npm run build  # 生产构建
```
